# Fairy Data Workspace

Status: S5 source governance baseline
Owner: @TechLead

This directory separates source retention from publishable cleaned data.

## Layout

| Path | Purpose | Git | npm/package distribution |
|---|---|---:|---:|
| `source/excel/` | lo-user supplied workbook and metadata | yes | no |
| `source/raw/` | fetched raw JSON / JS / HTML source snapshots | yes | no |
| `source/source-manifest.json` | checksums and source usage metadata | yes | no |
| `cleaned/` | staging area for cleaned derived JSON generated by `@fairy/data` | yes | copied into `packages/data/cleaned/` before package publishing |

Raw source archives are retained so future data cleaning can be audited, but V1
package outputs must expose only cleaned JSON and TypeScript types. Do not place
hand-authored formal game data in this directory.

Publishing boundary: repo-root `data/cleaned/` is the canonical generated
staging directory. `packages/data/scripts/sync-cleaned.mjs` mirrors generated
JSON into `packages/data/cleaned/`, because npm packages cannot include files
outside the package root.
