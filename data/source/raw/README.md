# Raw Source Archive

This directory stores source-format snapshots fetched from approved sources.
Raw files are retained in git for auditability but are excluded from npm/package
distribution by `.npmignore` and package allowlists.

Rules:

- Store raw payloads under a source-specific subdirectory.
- Record URL, fetchedAt, SHA-256, HTTP metadata, and purpose in a sidecar
  metadata file.
- Do not include beta / leak / non-live-server content.
- Do not copy raw source values into formal data by hand; cleaned outputs must
  be generated by parser code and retain source anchors.
