# Cleaned Data Outputs

Generated cleaned JSON is written here by S5 tasks. This directory is the
repo-level staging area for publishable data. Before publishing `@fairy/data`,
run `pnpm --filter @fairy/data sync-cleaned` to mirror JSON files into
`packages/data/cleaned/`, which is the actual npm package payload directory.

Rules:

- Files must be generated by `@fairy/data` importers from source documents.
- JSON must include or reference source metadata sufficient for audit.
- No raw source JSON, HTML, JS, images, full Excel workbook, or bulk table dump
  belongs here. Normalized calculation-relevant source text is allowed only when
  it has source refs, hashes, and parser metadata.
- No hand-authored formal game data belongs here.

Current generated artifacts:

- `audit/v1-agent-source-candidates.json` — minimal Excel-derived source
  candidates for V1 team-modifier replay.
- `audit/nicole.acceptance.json` and `audit/yanagi.acceptance.json` —
  lo-user manual acceptance records for G22/G23 source-text mappings.
- `golden/v1-replay-report.json` — source-backed V1 golden replay report.
