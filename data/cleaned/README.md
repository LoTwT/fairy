# Cleaned Data Outputs

Generated cleaned JSON will be written here by later S5 tasks. This directory is
the repo-level staging area for publishable data. Before publishing `@fairy/data`,
run `pnpm --filter @fairy/data sync-cleaned` to mirror JSON files into
`packages/data/cleaned/`, which is the actual npm package payload directory.

Rules:

- Files must be generated by `@fairy/data` importers from source documents.
- JSON must include or reference source metadata sufficient for audit.
- No raw source JSON, HTML, JS, images, or Excel workbook content belongs here.
- No hand-authored formal game data belongs here.
