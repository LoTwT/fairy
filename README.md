# Fairy

Fairy is a Zenless Zone Zero (ZZZ) damage calculator.

The project is restarting from a clean slate. The previous implementation
(npm `@randomplay/core` / `data` / `cli`, versions `0.0.1`–`0.1.4`) is kept only
as history; the new build does not reuse its code. See
[docs/history/](docs/history/) for the record and
[docs/rfcs/0001-clean-slate-reset.md](docs/rfcs/0001-clean-slate-reset.md) for why.

## Documentation

[docs/index.md](docs/index.md) is the single entry point — it says where
everything lives. Agent instructions are in [AGENTS.md](AGENTS.md).

## Status

Resetting. The new product direction and architecture are not decided yet; they
will be proposed in a follow-up RFC. Until then there is no current build to run.
