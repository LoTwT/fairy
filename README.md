# Fairy

Fairy is a Zenless Zone Zero (ZZZ) damage calculator.

> **Status - clean-slate rebuild.** The project has been reset to a clean slate;
> the Phase 6B first implementation slice now provides `@randomplay/core` for
> the accepted `regular_damage` and `sheer_damage` calculation boundary. Product
> UI, package data, resolvers, optimizer, custom registries, CLI, npm publish,
> and the remaining formula families are not implemented. See
> [docs/index.md](docs/index.md) for the current project state, specs, and where
> things live.

Fairy publishes under the existing `@randomplay/*` npm scope (`@randomplay/core`
/ `data` / `cli`), kept for published-version continuity across the reset (see
[docs/references/history.md](docs/references/history.md)).
