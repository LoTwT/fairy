# Fairy

Fairy is a Zenless Zone Zero (ZZZ) damage calculator.

The project is restarting from a clean slate. The previous implementation
(npm `@randomplay/core` / `data` / `cli`, versions `0.0.1`–`0.1.4`) is treated as
legacy and will be cleared in a follow-up PR; the new build does not reuse its
code. See [docs/references/history.md](docs/references/history.md) for the record
and [docs/specs/0001-clean-slate.md](docs/specs/0001-clean-slate.md) for why.

## Documentation

[docs/index.md](docs/index.md) is the single entry point — it says where
everything lives. Agent instructions are in [AGENTS.md](AGENTS.md).

## Status

Resetting. The pre-reset code is still in the tree until the clearing PR and is
legacy only. The new product direction and architecture are not decided yet; they
will be proposed in a later spec.
