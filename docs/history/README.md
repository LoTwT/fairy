# History

This folder records the pre-reset fairy: which versions shipped and what was
removed when the project restarted from a clean slate.

**This is read-only history.** It exists for traceability. It is never a source
for new implementation — see the clean-slate rule in [../../AGENTS.md](../../AGENTS.md).

- [npm-versions.md](npm-versions.md) — every published npm version, with tag,
  commit, publish time, and links.
- [archive-index.md](archive-index.md) — what the reset removed and how to
  recover it.

The old code itself is not copied here; it is recoverable from git tags
(`v0.0.1`–`v0.1.4`) and the npm registry.
