# PR A 实施与交接

状态：PR A 实现及评审修复已完成；提交与合并状态以 Git 和 PR 记录为准。
正式数据契约统一维护在 [60 级属性规范](../specs/data/panel-attributes.md)，本页仅记录评审处理与交接。

## 已实施

- 三个异步读取接口、正式类型和按实体拆分的静态 JSON；58 名角色、95 个音擎、通用 S 级满强化驱动盘词条。
- 固定输入的候选生成器、来源/制品 manifest、精确成员与字节校验。
- 原始快照获取与派生属性校验分开；消费准备和构建冻结 definitions，发布只复制本次固定副本。
- 纯转换、独立固定样本、API 隔离、发布一致性、包名消费、公开类型与浏览器按需请求验收。

## 六项评审的处理

| 事项                             | 处理                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| 常驻被动转化缺口                 | 角色基线明确不含本的防御转攻击等转化；PR C 必须补齐，已结算输入不得再次应用           |
| 属性类型/单位/运算未完全固定     | 正式 TypeScript 类型和显式 prop/name2 映射；未知字段或单位拒绝生成                    |
| 生成与旧制品校验可能循环         | `preparePublication` 保持来源获取职责；`prepareDefinitions` 独立校验派生属性          |
| 构建中途读取变化后的 definitions | 构建准备阶段冻结全部 definitions 和 manifest；结束只复制并验证独占副本                |
| 候选安装协议不清                 | 生成命令只接收新目录，不覆盖正式制品；普通失败清理，中断候选丢弃重建                  |
| 证据与独立数值样本不足           | 固定公式 URL/摘要/用途，保留 93 个音擎的上游显示攻击样本与摘要，具名差异写入 manifest |

## 实现 review 修复

- 冻结 definitions 后复验来源的完整文件集合与字节，拒绝捕获期间的替换、增加和删除；effects 与属性制品使用同一边界。
- 属性和静态增益生成器共用候选路径预检，覆盖来源目录、控制目录、路径别名、来源/控制目录最终符号链接、缺失父目录和 Unicode 大小写变体；具体契约见[消费与发布边界](../specs/data/consumption.md#静态发布与受管理目录边界)。
- 两个生成器共用独占创建目标的安装步骤，修复空目录被另一生成器替换、两方均成功但输出混杂的并发问题；失败仅清理本次取得的输出。
- 发布回归测试共 15 项，覆盖捕获期间替换/增加/删除、受保护路径、来源/控制目录最终链接、输出竞争与失败清理。新增路径用例及完整生成器并发实验均已确认旧实现失败、修复后通过。
- 在临时静态副本上使用固定来源完成候选生成，155 个制品验证通过；危险输出被拒绝后，来源副本继续通过完整校验。
