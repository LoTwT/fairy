# D6 缺口审计与收尾决定

日期：2026-10-22

本页记录 D6-2 oracle 补齐后的剩余缺口审计。逐条权威数据仍是
[静态覆盖报告](../../../packages/data/definitions/effects/static-coverage.json)；
本页只记录分类、决定和后续触发条件，不复制每条记录的完整说明。

## 当前计数

- 静态 effects：1,167 converted、116 corrected、77 unsupported。
- 补充来源：101 条记录，68 条已整合，33 条 out-of-scope。
- 技能动作：62 名成员、1,348 条动作；4 条 unavailable。
- core oracle：1,688 条 case，覆盖全部 1,167 个 converted 来源位置。

## 77 条 unsupported

全部 `reason` 均为 `semantic-conflict`，不是转换器漏读。主要包括：

- 完整状态迁移入口：原半状态/部分记录已并入完整状态选项，旧位置保留身份但不再独立贡献，例如简、莱特、猫又、菲欧妮、洛克茜、零号·安比、柚叶、蕾米埃尔与柳的部分记录。
- 来源语义冲突：固定来源的字段范围与 Nanoka/块 note 不一致，或同句条款需要尚未建立的条件模型；宁可不计算也不猜。
- 这些位置由 coverage 的 `explanation` 逐条说明，并由完整状态选项、具名差异用例或显式拒绝测试覆盖。

**决定**：不强行把 unsupported 改成 converted。当前计算范围只覆盖已核实的伤害乘区；没有独立证据时不新增公式。

## 116 条 corrected

这些记录已有明确修正来源，并登记在 31 个 `differenceId` 中。数量较大的类别包括：

- 音擎固定回能字段的单位/来源修正。
- 潜能分支和潜能表达式。
- 核心等级参数、特殊技等级表达式。
- 完整状态合并（昂扬、柚叶、菲奥妮等）。
- 元素范围、倍率编码、承伤/减防范围等具名修正。

**决定**：保持 corrected；每条修正继续由具名测试和 coverage 解释约束，不把修正结果伪装成固定源原值。

## 33 条 out-of-scope 补充来源

这些条款不属于当前“己方对敌伤害”输出：

- 失衡值/失衡持续时间。
- 即时能量、喧响值、角色特殊资源、能量获得效率。
- 己方承伤、攻击者减伤、[秽息浸染]。
- 异常积蓄值/积蓄抗性/积蓄效率。
- 护盾值。

**决定**：保持 `formula-out-of-scope`，不折算成增伤、减防、异常精通或 `energyRegen`，也不记为零贡献。对应选项显式选择时返回具名拒绝。只有未来新增承伤、资源或失衡产品能力时，才重新评估接入。

## D4 覆盖层测试

24 条旧 D4 用例仍以 `describe.skip` 保留。原因是它们依赖已删除的 3.2.5 overlay 选项契约，而 1631/1641 的固定源动作目录已由 D6-1 补齐；动作目录本身不再构成阻塞。

**决定**：暂时保留 skip，不伪造 overlay 选项恢复测试。若未来需要重新引入 D4 完整状态或六元素异放选项，应先重建对应目录契约，再恢复这些用例。

## 结论

D6-2 的 oracle 缺口已关闭。剩余 unsupported、corrected 与 out-of-scope 均是已登记的来源冲突、迁移入口或产品范围外条款，不是本轮可安全自动修复的转换遗漏。

后续只有三类触发条件会重启这些条目：

1. 固定来源或 Nanoka 提供可区分的新结构化记录。
2. 产品新增承伤、资源、失衡值或护盾计算范围。
3. D4 overlay 选项契约被明确重新引入。
