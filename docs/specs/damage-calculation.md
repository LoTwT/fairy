## 2. 各乘区定义与计算规则

### 2.1 基础伤害区

```
基础伤害区 = Σ(伤害倍率 × 对应属性)
最终属性 = 初始属性 × (1 + 最终属性加成%) + 最终属性固定值加成
初始属性 = 基础属性 × (1 + 初始属性加成%) + 初始属性固定值加成
```

- 绝大多数伤害基于**攻击力**
- 贯穿伤害基于**贯穿力**（命破特性专属，本质是特殊攻击力）
  - 仪玄：`贯穿力 = 攻击力 × 0.3 + 生命值上限 × 0.1`
- 真实伤害仅计算基础伤害区，通常基于目标最大生命值

### 2.2 增伤区

```
增伤区 = 1 + Σ增伤
```

- 有效范围：`[0, 6]`
- 包含属性增伤、技能类型增伤、攻击类型增伤等，一律**加算**
- **不包含**贯穿增伤和异常增伤

### 2.3 暴击区

```
暴击区 = 1 + 暴击伤害  （暴击时）
暴击区 = 1              （未暴击时）
暴击期望 = 1 + 暴击率 × 暴击伤害
```

- 代理人基础：暴击率 5%，暴击伤害 50%
- 暴击率有效范围：`[0, 1]`
- 暴击伤害有效范围：`[0, 5]`
- 暴击区实际有效范围：`[1, 6]`

### 2.4 防御区

```
防御区 = 攻击方等级基数 / (受击方有效防御 + 攻击方等级基数)
受击方有效防御 = 受击方防御 × (1 - 攻击方穿透率%) - 攻击方穿透值  ≥ 0
受击方防御 = (基础防御 × (1 + 初始防御%) + 初始固定防御) × (1 + 防御加成% - 防御降低%)
```

简化（代理人/邦布攻击敌人）：

```
敌人有效防御 = 基础防御 × (1 + 防御加成% - 防御降低% - 无视防御%) × (1 - 穿透率%) - 穿透值
```

- **无视防御**与减防**加算**；**穿透率**与减防**乘算**
- 有效范围：`(0, 1]`，目前游戏最低约 0.0283
- 贯穿伤害**跳过此乘区**

敌人基础防御：

```
某等级基础防御 = 1级基础防御 / 50 × 该等级攻击方等级基数
```

- 普通敌人 1 级基础防御：36–46
- 精英敌人 1 级基础防御：45–54（杜拉罕 58）
- 首领敌人 1 级基础防御：60，60 级及以上为 **952.8**

**秽盾状态下防御区**：`794 / (952.8 × 1.8 + 794) = 0.3165`（约 31.65%）

### 2.5 抗性区

```
抗性区 = 1 - 受击方抗性 + 受击方抗性降低 + 攻击方无视抗性
```

- 有效范围：`[0, 2]`
- 弱点属性抗性 = -0.2；抗性属性抗性 = 0.2
- 适用于伤害抗性、失衡抗性、异常积蓄抗性（三者独立，不混用）

### 2.6 减易伤区

```
减易伤区 = 1 + 受击方易伤 - 受击方减伤
```

- 有效范围：`[0.2, 2]`（无法通过叠加减伤归零）
- 秽盾时敌人获得 25% 减伤加成（秽蚀·色雷斯人 60%）

### 2.7 失衡易伤区

```
失衡易伤区 = 1 + 失衡易伤倍率     （失衡时）
失衡易伤区 = 1 + 未失衡时失衡易伤倍率  （未失衡时）
```

- 失衡时有效范围：`[0.2, 5]`
- 未失衡时有效范围：`[1, 3]`
- 默认失衡易伤倍率：25%、50%、100% 三档

### 2.8 贯穿增伤区（贯穿伤害专属）

```
贯穿增伤区 = 1 + 贯穿增伤
```

- 有效范围：`[0.2, 9]`
- 替代防御区，仅作用于贯穿伤害

### 2.9 异常精通区（异常/紊乱伤害）

```
异常精通区 = floor(异常精通) / 100
```

- 有效范围：`[0, 10]`（即异常精通上限 1000）
- 计算时异常精通向下取整

### 2.10 伤害等级区（异常/紊乱伤害）

```
伤害等级区 = trunc(1 + (等级 - 1) / 59, 4)
```

- trunc(…, 4)：向下保留 4 位小数
- 1 级 = 1.0000；60 级 = 2.0000

### 2.11 异常增伤区

```
异常增伤区 = 1 + 异常伤害提升
```

- 有效范围：`[0, 3]`
- 紊乱伤害默认不受针对单一属性异常的增伤效果影响

### 2.12 异常暴击区

```
异常暴击区 = 1 + 异常暴击伤害  （暴击时）
异常暴击区 = 1                  （未暴击时）
异常暴击期望 = 1 + 异常暴击率 × 异常暴击伤害
```

- 有效范围：`[1, 3]`（对应 `anomalyCritDamage` 有效范围 `[0, 2]`）
- 期望值计算中 `anomalyCritRate` clamp 到 `[0, 1]`，`anomalyCritDamage` clamp 到 `[0, 2]`

## 3. 常规伤害完整公式

```
常规伤害 = 基础伤害区 × 增伤区 × 暴击区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区 × 特殊乘区
```

---

## 4. 贯穿伤害完整公式

```
贯穿伤害 = 基础伤害区 × 增伤区 × 暴击区 × 贯穿增伤区 × 抗性区 × 减易伤区 × 失衡易伤区 × 特殊乘区
```

与常规伤害的差异：

- **无防御区**（跳过）
- **有贯穿增伤区**（替代防御区位置）
- 基础伤害区基于**贯穿力**而非攻击力

对默认首领（60 级以上）：贯穿伤害为常规伤害的 `1/0.4545 ≈ 2.2` 倍（其他条件相同时）。
秽盾状态：贯穿伤害为常规伤害的 `1/0.3165 ≈ 3.16` 倍。

---

## 5. 异常伤害完整公式

```
异常伤害 = 基础伤害区 × 增伤区 × 异常精通区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区 × 伤害等级区 × 异常增伤区 × 异常暴击区
```

### 虚拟代理人机制

- 计算属性异常伤害时，绝区零记录每次造成异常积蓄的代理人属性（等级、异常精通、攻击力、冲击力、穿透率、穿透值、增伤区、失衡值提升区）
- 按**各代理人积蓄占比**（排除邦布积蓄、溢出部分）加权平均，得到**虚拟代理人**
- 虚拟代理人的等级向下取整
- 防御区、抗性区、减易伤区、失衡易伤区**实时结算**（基于敌人当前属性）
- 异常增伤区、异常暴击区**实时结算**

---

## 6. 紊乱伤害完整公式

```
紊乱伤害 = 基础伤害区 × 增伤区 × 异常精通区 × 防御区 × 抗性区 × 减易伤区 × 失衡易伤区 × 伤害等级区 × 异常增伤区 × 异常暴击区
```

与普通异常伤害相同的乘区结构，差异在于**基础伤害区中的伤害倍率**：

### 各属性紊乱倍率公式

| 属性         | 基础异常 | 紊乱倍率公式                    | 初始持续时间 T |
| ------------ | -------- | ------------------------------- | -------------- |
| 火（灼烧）   | —        | `450% + floor(T / 0.5) × 50%`   | 10 s           |
| 电（感电）   | —        | `450% + floor(T) × 125%`        | 10 s           |
| 以太（侵蚀） | —        | `450% + floor(T / 0.5) × 62.5%` | 10 s           |
| 冰（霜寒）   | —        | `450% + floor(T) × 7.5%`        | 10 s           |
| 物理（畏缩） | —        | `450% + floor(T) × 7.5%`        | 10 s           |
| 玄墨（侵蚀） | —        | `450% + floor(T / 0.5) × 62.5%` | 10 s           |
| 烈霜（霜寒） | —        | `600% + floor(T) × 75%`         | **20 s**       |

- T：原异常状态**剩余持续时间**（秒）
- 紊乱触发时原异常状态被覆盖（结算后消失）
- 紊乱基于原异常的**虚拟代理人**属性；异常增伤区/暴击区实时结算

### T 值计算示例

- 火属性灼烧，T = 10s（满持续）：`450% + floor(10/0.5) × 50% = 450% + 20 × 50% = 1450%`
- 电属性感电，T = 10s（满持续）：`450% + floor(10) × 125% = 450% + 10 × 125% = 1700%`
- 烈霜霜寒，T = 20s（满持续）：`600% + floor(20) × 75% = 600% + 20 × 75% = 2100%`

## 7. 特殊规则

### 7.1 距离衰减

- 默认型（比利、丽娜、朱鸢等）：距离 > 15m 时衰减 25%，每再远 5m 再衰减 25%
- 格莉丝型：距离 > 15m 时衰减 30%
- 同时影响伤害、失衡值和异常积蓄值
- 在本模块中通过 `specialMultiplier` 参数传入（如衰减 25% 则传 `0.75`）

### 7.2 伤害取整

- 游戏中伤害显示**向上取整**
- 多段伤害：每段分别向上取整后相加
- **本模块返回的 `DamageResult.total` 为未取整的原始值**，调用方根据需要自行 `Math.ceil`

### 7.3 秽盾机制

| 条件                          | 防御区                               |
| ----------------------------- | ------------------------------------ |
| 60 级攻 60 级以上首领，无秽盾 | `794 / (952.8 + 794) ≈ 0.4545`       |
| 同上，有秽盾（防御 +80%）     | `794 / (952.8 × 1.8 + 794) ≈ 0.3165` |

秽盾附加减伤：

- 普通秽盾：-25% 减伤
- 秽蚀·色雷斯人：-60% 减伤

## 8. TypeScript 类型签名（实现参考）

```typescript
// === 乘区参数类型 ===

interface DefenseParams {
  attackerLevelBase: number // 攻击方等级基数（查等级基数表）
  defenderBaseDefense: number // 受击方防御（已含初始属性加成，仅保留防御加成/降低/穿透层）
  defenseBonus: number // 防御加成%（小数，如 0.8 = 80%）
  defenseReduction: number // 防御降低%（减防，无视防御，加算）
  penetrationRate: number // 穿透率%（小数）
  penetrationValue: number // 穿透值（固定值）
}

interface ResistanceParams {
  defenderResistance: number // 受击方属性抗性（小数，如 -0.2 = 弱点）
  resistanceReduction: number // 攻击方抗性降低
  ignoreResistance: number // 攻击方无视抗性
}

interface VulnerabilityParams {
  vulnerabilityBonus: number // 易伤（受到的伤害提升）
  damageReduction: number // 减伤（受到的伤害降低）
}

interface DazeVulnerabilityParams {
  isStunned: boolean // 是否处于失衡状态
  stunVulnerability: number // 失衡易伤倍率
  nonStunVulnerability: number // 未失衡时失衡易伤倍率
}

interface CritParams {
  critRate: number // 暴击率（小数）
  critDamage: number // 暴击伤害（小数）
}

// === 各伤害类型完整参数 ===

interface NormalDamageParams {
  baseDamage: number // 基础伤害区结果（攻击力 × 伤害倍率）
  bonusDamageSum: number // 增伤区加总（小数）
  crit: CritParams
  defense: DefenseParams
  resistance: ResistanceParams
  vulnerability: VulnerabilityParams
  dazeVulnerability: DazeVulnerabilityParams
  specialMultiplier?: number // 特殊乘区（如距离衰减，默认 1）
}

interface SheerDamageParams {
  baseDamage: number
  bonusDamageSum: number
  crit: CritParams
  sheerBonusSum: number // 贯穿增伤区加总（小数）
  resistance: ResistanceParams
  vulnerability: VulnerabilityParams
  dazeVulnerability: DazeVulnerabilityParams
  specialMultiplier?: number
}

interface AnomalyDamageParams {
  // 虚拟代理人属性
  virtualAgentLevel: number
  virtualAgentAttack: number
  virtualAgentAnomalyProficiency: number // 异常精通（内部取整）
  damageMultiplier: number // 异常伤害倍率（如 5.0 = 500%）
  bonusDamageSum: number // 增伤区加总（虚拟代理人快照，小数）
  // 敌方乘区（实时结算）
  defense: DefenseParams
  resistance: ResistanceParams
  vulnerability: VulnerabilityParams
  dazeVulnerability: DazeVulnerabilityParams
  // 异常专属
  anomalyBonusDamageSum: number // 异常增伤区加总（紊乱不受单一属性异常增伤影响，传 0）
  anomalyCritRate: number
  anomalyCritDamage: number
}

interface DisorderDamageParams extends Omit<
  AnomalyDamageParams,
  "damageMultiplier"
> {
  anomalyType: AnomalyType
  remainingTime: number // 原异常状态剩余持续时间（秒）
}

// === 返回结构 ===

interface DamageResult {
  total: number
  breakdown: {
    baseDamage: number
    bonusMultiplier: number
    critMultiplier: number
    defenseMultiplier: number // 贯穿伤害固定为 1（跳过防御区）
    resistanceMultiplier: number
    vulnerabilityMultiplier: number
    dazeVulnerabilityMultiplier: number
    sheerBonusMultiplier: number // 非贯穿伤害固定为 1
    anomalyProficiencyMultiplier: number // 非异常/紊乱伤害固定为 1
    damageLevelMultiplier: number // 非异常/紊乱伤害固定为 1
    anomalyBonusMultiplier: number // 非异常/紊乱伤害固定为 1
    anomalyCritMultiplier: number // 非异常/紊乱伤害固定为 1
    specialMultiplier: number
  }
}

type AnomalyType =
  | "fire"
  | "electric"
  | "ether"
  | "ice"
  | "physical"
  | "auricInk"
  | "frost"
```

## 9. 参考数值

- 60 级攻击者 vs 60+ 级首领默认防御区：`794 / (952.8 + 794) = 0.4545`
- 60 级攻击者 vs 60+ 级首领秽盾防御区：`794 / (952.8 × 1.8 + 794) = 0.3165`
- 60 级伤害等级区：`trunc(1 + 59/59, 4) = 2.0000`
- 1 级伤害等级区：`trunc(1 + 0/59, 4) = 1.0000`
- 火属性灼烧 T=10s 紊乱倍率：`450% + 20×50% = 1450%`
- 电属性感电 T=10s 紊乱倍率：`450% + 10×125% = 1700%`
