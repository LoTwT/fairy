# 伤害显示总值

伤害显示总值帮助函数将每段未显示取整的伤害分别向上取整，再按顺序汇总为显示总值。规则来源为
[原始攻略中的伤害显示说明](../../../references/zzz-data-introduction.txt#L47)。

## 公开契约

| 项目     | 定义                                   |
| -------- | -------------------------------------- |
| 中文名称 | 伤害显示总值                           |
| 公开函数 | `calculateTotalDisplayedDamage`        |
| 输入类型 | `readonly number[]`                    |
| 结果语义 | 各段分别向上取整后相加得到的显示伤害值 |

```ts
/** 将每段未显示取整的伤害分别向上取整后，按顺序汇总为显示伤害总值。 */
export declare function calculateTotalDisplayedDamage(
  unroundedSegmentDamageValues: readonly number[],
): number
```

函数只有一个同质数值集合输入，不增加只包装该数组的参数对象或公开类型。返回值是普通 `number`，不返回
逐段取整结果、`FactorResult` 或 `FormulaResult`。

## 输入语义

`unroundedSegmentDamageValues` 的每个成员表示一个伤害段完成全部适用乘区计算后、尚未执行显示
取整的最终伤害。当前常规伤害、贯穿伤害和异常伤害可以分别使用对应 `FormulaResult.value` 建立该数组，
不传入完整的 `FormulaResult`。

调用方负责划分伤害段和一次汇总包含的范围。同一个技能、攻击或异常效果包含多个伤害段时，调用方
必须先分别计算各段的未取整伤害，再将这些结果传入本函数。本函数不能从一个已经聚合的伤害值、技能
数据或 Nanoka 记录中还原伤害段。

## 数组语义

- 空数组表示本次没有需要汇总的伤害段，结果为 `0`。这是 core 为求和定义的恒等输入，不表示游戏
  中存在零段攻击。
- 每个成员对应一个独立伤害段。内容相同的成员不会合并或去重，重复成员分别参与取整和汇总。
- 成员按数值索引从小到大读取、取整和累加，数组顺序不表示业务优先级。
- 稀疏数组的空位按对应索引读取为 `undefined`，不属于有效成员。
- 函数不得修改、冻结或替换输入数组。

## 计算规则

```text
单段显示伤害 = ceil(unroundedSegmentDamageValues[index])
伤害显示总值 = Σ 单段显示伤害
```

函数必须对每个成员分别执行 JavaScript `Math.ceil`，再按数组索引顺序相加。不能先汇总未取整伤害后
只向上取整一次，也不能添加 epsilon 修正、固定小数位处理或其他格式化逻辑。

输入成员必须是非负有限数，`0` 有效。攻略没有给出伤害值上限，因此不增加安全整数范围或其他上限。
负数不表示当前三类伤害公式的合法结果，由本函数作为无效输入拒绝；这是 core 的输入契约，不是对游戏
负伤害显示行为的推断。

取整和顺序累加遵循 JavaScript `number` 的 IEEE 754 语义。函数不进行代数重排，也不承诺超出安全整数
范围后的整数精度。公开返回前必须检查最终结果是否有限。

单成员数组自然退化为一次单段显示取整。例如 `[10.2]` 的结果为 `11`；多段 `[10.2, 20.1]` 的结果为
`32`，不能按未取整总和 `30.3` 得到 `31`。

## 适用边界

攻略在常规伤害和贯穿伤害公式之后直接给出该显示规则，因此两类伤害可以使用本函数。攻略对“游戏中的
伤害显示”使用了不限定伤害类型的表述，当前异常伤害规范也采用同一显示数值取整与汇总规则。本函数不
接收伤害类型字段；调用方必须先确认待处理的伤害类型适用该规则。

真实伤害尚未纳入当前 core 规范，现有来源也没有单独确认真实伤害的显示取整方式，因此不能仅凭本函数
存在就认定真实伤害采用相同规则。失衡值、异常积蓄值、资源回复和秽盾削减值不是伤害显示值，也不使用
本函数。

本函数只计算伤害数字的显示总值，不负责：

- 选择或调用具体伤害公式，建立公式输入，或判断一次伤害属于常规、贯穿还是异常伤害；
- 判断攻击包含多少伤害段，或按技能、目标、帧、持续伤害间隔和数字合并时窗分组；
- 计算暴击期望，决定是否暴击，或补充任何伤害乘区；
- 读取目标生命值、写入生命值变化，或断言显示伤害等于实际生命值扣除量；
- 生成 UI 文本，处理颜色、样式、千位分隔或其他显示格式。

本计算是伤害公式之后的公开帮助函数，不是 `Factor` 或 `Formula`，不提供身份常量或默认输入常量。

## 有效性与失败行为

| 失败条件                                        | 行为              |
| ----------------------------------------------- | ----------------- |
| 输入不是数组                                    | 抛出 `TypeError`  |
| 任一数组成员不是 `number`                       | 抛出 `TypeError`  |
| 任一数组成员是 `NaN`、`Infinity` 或 `-Infinity` | 抛出 `RangeError` |
| 任一数组成员小于 `0`                            | 抛出 `RangeError` |
| 逐段取整并汇总后的最终结果不是有限数值          | 抛出 `RangeError` |

多个失败条件同时存在时，不承诺校验错误的优先级。所有成员都合法且最终结果有限时，函数返回伤害显示总值。

## 代码组织

生产代码统一放在 `packages/core/src/damage.ts`，只包含伤害显示相关的公开函数及其私有计算逻辑。可复用的
运行时断言继续放在 `packages/core/src/internal/assert.ts`，不得从包入口公开导出。

`packages/core/src/index.ts` 只负责重新导出公开函数，测试保存在 `packages/core/test/damage.test.ts`。测试
必须覆盖单段与多段差异、空数组、稀疏数组空位、索引顺序、重复值、输入不可变性、失败行为和最终汇总
溢出。打包验证必须从安装后的包入口调用该函数。
