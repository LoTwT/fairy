# 特殊乘区边界

原始攻略把距离衰减列入“特殊乘区”，但明确说明其完整机制尚未探明。本规范只确定当前 core 的支持
边界，不定义可实现的统一乘区。规则来源为
[原始攻略中的特殊乘区](../../../references/zzz-data-introduction.txt#L145)。

## 当前结论

“特殊乘区”是尚未被其他已知乘区覆盖的机制分类，不是一个具有统一输入结构和计算规则的具体
`Factor`。不同机制被归入同一分类，不代表它们可以共享同一个算法。

当前不得公开以下 API：

- `SPECIAL_FACTOR_ID`；
- `specialFactor`；
- `SpecialFactorInput`；
- 接收任意预计算倍率的通用特殊乘区。

当某项特殊机制的规则被完整确认后，应为该机制建立独立规范、独立 `factorId` 和独立输入类型。顶层
公式可以采用一个或多个这样的具体乘区，但不得把它们重新包装成通用 `specialFactor`。

## 顶层公式边界

顶层公式处理特殊机制时必须区分以下情况：

- 已确认本次计算不适用特殊机制时，顶层组合直接使用恒等倍率 `1`，不需要调用一个占位乘区。
- 已知本次计算适用某项特殊机制，但该机制尚未实现时，不能静默按 `1` 结算，也不能声称结果完整。
- 无法确认本次计算是否适用特殊机制时，由调用方补充上下文；core 不猜测为“不适用”。

core 不提供“直接传入最终倍率”的兜底入口。否则调用方可以绕过具体乘区的输入语义、有效范围和
校验规则，特殊乘区也会退化成无法分析的任意数值容器。

## 已知距离衰减信息

距离衰减会影响代理人技能造成的伤害、失衡值和异常积蓄值。原始攻略目前只记录了以下不完整信息：

| 类型     | 距离条件   | 已知效果                                 |
| -------- | ---------- | ---------------------------------------- |
| 默认型   | 超过 `15m` | 衰减 `25%`；每继续远离 `5m` 再衰减 `25%` |
| 格莉丝型 | 超过 `15m` | 衰减 `30%`                               |
| 扳机型   | 未确认     | 攻略只确认该类型存在                     |
| 耀嘉音型 | 未确认     | 攻略只确认该类型存在                     |

这些信息不足以形成可实现规范，尤其尚未确认：

- 默认型的多段衰减采用百分点累减还是逐段乘算；
- 距离边界、最大衰减和最低倍率的精确规则；
- 每种类型的完整曲线及适用技能映射；
- 扳机型与耀嘉音型的计算规则；
- 多项特殊机制同时适用时的组合方式。

在这些规则确认前，不得从表中常量推导或实现距离衰减 `Factor`。

## 后续进入条件

一项特殊机制只有同时具备以下事实，才能新增具体乘区规范：

1. 稳定的机制身份和适用条件；
2. 完整、确定的输入结构；
3. 已确认的计算规则与常量；
4. 有效范围、边界值及越界处理；
5. 至少一组可用于测试的可复现样例。

规则进入具体乘区后，本文件只保留分类边界并链接至该乘区规范，不重复维护其算法。
