## Non-goals

- 不定义 package schema、runtime API、TypeScript type 或 package data。
- 不写 scraper、cleaner、resolver、calculation runtime 或 Phase 6 code structure。
- 不建立完整角色、技能、驱动盘、音擎、邦布、敌人、异常或装备数据库。
- 不把 2.0 baseline 说成 3.0 final truth。
- 不把 future formula areas 放入 accepted core formula list。
- 不把 guide-only mapping examples 当作 observed Phase 2/3 evidence。
