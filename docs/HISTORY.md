# History

Fairy is a Zenless Zone Zero (ZZZ) damage calculator. Its historical monorepo
published `@randomplay/core`, `@randomplay/data`, and `@randomplay/cli`.

This file is a recovery record. It is not a current product, API, data, or
implementation contract.
